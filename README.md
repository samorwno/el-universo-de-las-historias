# El Universo de las Historias

Secuencia didáctica interactiva sobre **textos narrativos** para **Lengua Castellana de 5°**. Recorre el cuento, la fábula, el mito y la leyenda, y cierra con un laboratorio para crear historias.

## Características

- Un único archivo `index.html` autónomo: no requiere instalación, servidor ni conexión a internet.
- Diseño responsive para móvil y escritorio.
- Navegación por pestañas: General, El Cuento, La Fábula, Mitos y Leyendas, En Internet y Laboratorio Final.
- Ejercicios interactivos con retroalimentación inmediata.
- Máquina "Crea-Historias" para generar relatos a partir de personaje, lugar y conflicto.

## Uso

Abre `index.html` en cualquier navegador moderno o visita la versión publicada:

https://samorwno.github.io/el-universo-de-las-historias/
